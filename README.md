# CEREBRON Farm 14 — Energy

Mission: analyse et conception de systèmes énergétiques avec séparation stricte entre données, modèles, simulations, essais et exploitation réelle.

Principes: REALITY > COHERENCE; CLAIM <= EVIDENCE; SIMULATION != TEST; sécurité, rendement, disponibilité, coût, matières, réseau et impacts doivent être explicités.

Domaines: production électrique, réseaux, stockage, solaire, éolien, hydraulique, géothermie, nucléaire, hydrogène, carburants, thermique, efficacité énergétique, flexibilité, économie énergétique, sûreté, résilience et intégration système.
